Mode d'emploi

📱 Outlook sur Android
  1. Ouvre cette page dans Chrome sur le téléphone (bouton 🔗 ci-dessus pour t'envoyer le lien).
  2. Choisis Version téléphone, puis 📋 Copier la signature.
  3. Dans Outlook : photo de profil → ⚙️ Paramètres → Signature (choisis le compte si besoin).
  4. Efface l'ancienne signature, appui long → Coller, puis valide.

⚠️ Ne colle jamais le code HTML dans l'appli : elle ne l'interprète pas, c'est ce qui casse la mise en forme. Colle la signature « toute faite ».

Si les images disparaissent ou s'affichent mal une fois collées, décoche « Photo, logo et icônes… » : il reste une version texte propre, avec couleurs et liens.

🖥️ Outlook classique (Windows) — méthode la plus fiable
  1. Choisis Version ordinateur puis Télécharger (.htm).
  2. Ouvre l'Explorateur de fichiers, tape %APPDATA%\Microsoft\Signatures dans la barre d'adresse, et dépose le fichier dedans.
  3. Outlook : Fichier → Options → Courrier → Signatures… : la signature apparaît dans la liste. Choisis-la pour les nouveaux messages et les réponses.

Avec cette méthode, Outlook garde la mise en page en colonnes. Un simple copier-coller marche aussi, mais Outlook peut alors empiler les blocs.

🖥️ Nouvel Outlook / Outlook sur le web
  1. Choisis Version ordinateur puis 📋 Copier la signature.
  2. ⚙️ Paramètres → Comptes → Signatures → Nouvelle signature.
  3. Colle (Ctrl+V), nomme-la, enregistre, puis choisis-la par défaut.
💡 Pourquoi elle est « responsive »
  • Les blocs (photo + logo, coordonnées, rdv / assistante, mentions) sont posés côte à côte tant que la place le permet, et passent les uns sous les autres sur un petit écran. Aucune zone ne déborde ni ne rétrécit en illisible.
  • Tout est en vrai texte (pas une grande image) : net sur tous les écrans, cliquable (appel, e-mail, rdv), lisible en mode sombre.
  • Photo, logo et icônes sont des PNG détourés, hébergés en ligne : ils restent propres sur fond blanc comme sur fond sombre.
  • Certains destinataires (Outlook pro notamment) bloquent les images jusqu'à ce qu'ils cliquent « Télécharger les images » : le texte, lui, reste toujours lisible.

🖼️ Les images

Les images sont dans le dossier signature/img/ du dépôt. Elles doivent être accessibles en ligne (GitHub Pages activé sur le dépôt, ou copiées sur le site avpatrimoine.fr). Dans ce cas, indique l'adresse du dossier dans « Adresse des images ». Pour une meilleure photo, remplace antoine.png par une version carrée de 180 × 180 px.
