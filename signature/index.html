Mode d'emploi

📱 Outlook sur Android
  1. Ouvre cette page dans Chrome sur le téléphone (utilise le bouton 🔗 ci-dessus pour t'envoyer le lien).
  2. Choisis Version téléphone, puis 📋 Copier la signature.
  3. Dans Outlook : photo de profil → ⚙️ Paramètres → Signature (choisis le compte si besoin).
  4. Efface l'ancienne signature, appui long → Coller, puis valide.

⚠️ Ne colle pas le code HTML dans l'appli : elle ne l'interprète pas, c'est ce qui casse la mise en forme. Colle la signature « toute faite ».

Si le logo n'apparaît pas, décoche « Logo dans la version téléphone » : le texte, les couleurs et les liens restent.

🖥️ Outlook sur ordinateur (nouvel Outlook / Outlook web)
  1. Choisis Version ordinateur puis 📋 Copier la signature.
  2. Outlook : ⚙️ Paramètres → Comptes → Signatures → Nouvelle signature.
  3. Colle (Ctrl+V) dans la zone d'édition, nomme-la et enregistre. Choisis-la par défaut pour les nouveaux messages et les réponses.
🖥️ Outlook classique (Windows)
  1. Fichier → Options → Courrier → Signatures… → Nouveau.
  2. Colle (Ctrl+V) la signature copiée ici, puis OK.

Alternative : Télécharger (.htm), puis place le fichier dans %APPDATA%\Microsoft\Signatures (tape ce chemin dans l'Explorateur). Il apparaîtra dans la liste des signatures.

💡 Pourquoi c'est « responsive »
  • Outlook ignore les media queries : au lieu d'adapter la mise en page, la signature est conçue étroite (≈ 340 px max) et tient donc sur n'importe quel écran.
  • Texte réel (pas une image) : net sur tous les écrans, lisible en mode sombre, cliquable.
  • Numéros en tel: et e-mail en mailto: : un tap suffit sur mobile.
  • Logo : PNG hébergé en https, avec un fond blanc (pas transparent) pour rester visible en mode sombre.
👩‍💼 Signature de l'assistante

Onglet Assistante en haut : seuls ses infos perso changent, l'entreprise, le logo et les couleurs sont partagés. Remplis ses champs puis envoie-lui le lien 🔗 : elle ouvre le lien sur son ordinateur ou son téléphone et copie sa signature.

🖼️ Héberger le logo

Dépose le logo dans le dossier signature/img/ de ce dépôt. Avec GitHub Pages activé, il est accessible à une adresse du type https://aversichel.github.io/business-suivi/signature/img/logo.png. Le site web de l'entreprise fait aussi très bien l'affaire.
